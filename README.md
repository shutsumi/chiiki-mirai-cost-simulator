# 地域みらい留学「留学したら毎月いくら？シミュレーター」

地域みらい留学(https://c-mirai.jp/)の対象校について、志望校を選ぶと、入学後に「毎月かかる費用」「入学のときにかかる費用」「年に何回かかかる費用」の目安がわかる静的Webツールです。

公開ページ: https://yuuunaaa00.github.io/chiiki-mirai-cost-simulator/ (`docs/` フォルダをGitHub Pagesで公開)

仕様書: Googleドキュメント「費用・出口施策」(2026年10月更新版)

## ディレクトリ構成

```
simulator/
├── README.md                 # このファイル
├── data/                      # データ収集・加工の作業ディレクトリ(生データ・中間ファイル)

│   ├── raw_dump_part*.txt     # 各校ページから抽出した学費・生活費の生テキスト
│   ├── schools_cost_data.json # 構造化後の全校データ(raw_fee_block含む・確認用)
│   ├── prefecture_centroids.json
│   ├── school_locations.json  # 各校の緯度経度(国土地理院「地理院地図」住所検索で町域を検索)
│   ├── airports.json          # 定期便のある空港の一覧(OurAirports のデータから作成)
│   └── school_transport.json  # 各校の最寄り空港・フェリーが必要か

│   ├── enrich_prefecture.py   # 住所から都道府県・概算緯度経度を付与
│   ├── meal_provision.py      # 各校の食事提供条件(何食・何曜日)の判定結果 → data/meal_provision.json
│   ├── build_transport_data.py # 学校の最寄り空港・フェリーの要否を判定
│   ├── build_site_data.py     # 公開用の軽量データ docs/data/schools.json・airports.json を生成

    ├── app.js
    └── data/schools.json      # サイトが実際に読み込む軽量データ(scripts/build_site_data.pyで生成)
```

## データの取得方法(v1)

1. https://c-mirai.jp/schools の全ページ(page=1〜8)から、全189校のID・学校名を収集。
2. 各校の詳細ページ(`/schools/{id}`)をChromeブラウザ経由で取得し、「学費・生活費」セクションのテキストを抽出。
3. `scripts/parse_raw.py` で正規表現ベースの構造化を行い、以下を抽出:
   - 初年度経費(入学金・授業料・制服代等の内訳と合計)
   - 生活費(月額、住居費・食費・光熱費等の内訳と合計)
   - 居住タイプ(寮・シェアハウス・ホームステイ・一人暮らし等)ごとの説明文
4. `scripts/enrich_prefecture.py` で住所文字列から都道府県を判定し、距離計算用の概算座標(県庁所在地)を付与。


## 計算ロジック(v2 2026年11月 内海が引き継ぎ・改修)

### v2で決めたこと(2026-11-17 古志・内海の打ち合わせ、10〜11月の座談会の意見を反映)
- **検討時の費用(オープンスクール・受検の交通費・宿泊費)はなくした。** 経路・運賃の計算は実際と合わないことが多く(直行便のない路線が出るなど)、シミュレーターに背負わせない。自宅から学校までの行き方と運賃は、結果画面のGoogleマップへのリンク(`https://www.google.com/maps/dir/?api=1&destination=学校名`、APIキー不要・無料)で各自調べてもらう
- 入力は「学校のある都道府県」→「志望校」の2つだけ。ファーストビューに入力欄を置く(住所・居住地の入力はなし)
- 入学時・ときどきの費用まで足した総額は出さない。金額は「〜」つきの目安で出す
- 毎月かかる費用だけは「毎月の合計」を大きく出す(2026-11-19追加、合計がないとわかりづらいため)
  - 寮費・生活費＋学校に払う費用の月割り。授業料は就学支援金で実質0円として足さない。寮費・生活費が未公表の学校は合計を出さない
  - 食事が出ない日の食費・お小遣いは家庭や生徒で大きく変わるため合計に含めず、「別途かかる可能性がある費用」として目安だけ出す
- 1月下旬の中2以下向けイベント(「3年間いくらかかる？」)で使う予定。年内に完成させる

### 結果画面
1. **毎月かかる費用の目安**
   - 寮費・生活費: 学校ページの合計額を「○円〜」で表示。「食費込み」などの表示、住まいの種類(寮・シェアハウスなど)、内訳(開閉式)、注記を添える。未掲載は「学校へお問い合わせください」
   - 食事が出ない日の食費: 出ない食事数 × 300円(自炊)〜750円(自炊と外食1,200円の中間)の幅で表示。お小遣いとは分ける
     - 1か月 = 30日×3食 = 90食(平日22日・土曜4日・日曜4日)として、出ない食事数 = 90 − 提供される食数(`scripts/meal_provision.py` の判定結果)
     - 食費が生活費に含まれる学校(in_cost)は「生活費に含まれています」、提供条件が不明な学校は「学校へお問い合わせください」
   - お小遣い: 10,000円〜(ご家庭で決める金額の目安)
   - 学校に払う費用(月割り): 初年度の費用のうち、分割で払うことが多い3項目を月割りにする
     - 授業料: 年額 ÷ 12(学校ページに月額で載っている学校もあるため、2万円未満は月額とみなす)。就学支援金の申請で実質0円になることを表示する
     - 修学旅行積立金: 総額 ÷ 36 〜 総額 ÷ 24 の幅(積立期間や一括払いかは学校によって違うため)
     - 学校諸費: 年額 ÷ 12
2. **入学のときにかかる費用**: 上の3項目以外の項目名(入学金・制服など)と、家具・家電、引っ越し。金額は学校ページへのリンクで確認してもらう
3. **年に何回かかかる費用**: 帰省の交通費(Googleマップへのリンク)、部活の遠征・行事、冬の光熱費
4. **費用が下がるかもしれない情報**: 就学支援金、自治体の補助、学校ページの補足(`firstYearNotes`。町の補助などが書かれていることが多い)
5. **学校に確認しておきたいこと**

金額はすべて100円単位で丸める。

## 入力内容の記録(Googleスプレッドシート)

「費用を計算する」ボタンが押されるたびに、次の内容をスプレッドシートに1行ずつ記録します。氏名・メールアドレスなど、個人を特定できる情報は記録しません。

| 列 | 内容 |
|---|---|
| 受信日時 / 種類 | 記録した日時、「検討時」か「留学後」か |
| 居住地 | (v2では空欄。居住地の入力をなくしたため) |
| 学校1〜3 / 交通手段1〜3 / 宿泊日数1〜3 | v2では学校1だけを記録(交通手段・宿泊日数は空欄) |
| 最寄り空港 | (v2では空欄) |
| 帰省時期 | (現在は使っていない。帰省回数を選ぶ欄をなくしたため空欄) |
| 合計金額 | 画面に出す「毎月の合計」の下限(寮費・生活費が未公表なら空欄) |
| セッションID | ページを開くたびに作る8文字のランダムな文字(同じ人の連続した計算をまとめて見るため。保存はしない) |

### 設定方法

1. Googleドライブで、記録用のスプレッドシートを新しく作る
2. スプレッドシートの [拡張機能] > [Apps Script] を開き、`gas/Code.gs` の内容を貼り付けて保存する
3. [デプロイ] > [新しいデプロイ] で種類「ウェブアプリ」を選び、次のように設定してデプロイする
   - 次のユーザーとして実行: 自分
   - アクセスできるユーザー: 全員
4. 初回はGoogleアカウントの権限の確認が表示されるので、許可する
5. 表示された「ウェブアプリのURL」(`https://script.google.com/macros/s/.../exec`)を、`docs/config.js` の `logEndpoint` に設定する
6. シートは初回の記録時に「記録」という名前で自動作成される

`gas/Code.gs` を修正したときは、[デプロイ] > [デプロイを管理] から新しいバージョンとしてデプロイし直してください(URLは変わりません)。

## v1の既知の制約(今後の改善候補)

- **生活費の「合計0円」表示について**: 学校側のページ自体で金額が「調整中」「未定」となっているケースがそのまま反映されています(パースの不具合ではなく元データの状態です)。v2以降、学校への確認や更新チェックの仕組みを検討。
- **住居タイプが複数ある学校**: 生活費の合計金額は学校ページに記載された代表値であり、住居タイプ(寮/シェアハウス/ホームステイ等)ごとの金額差を完全には反映していません。各住居タイプの説明文(備考)はシミュレーター上に表示されますが、金額の自動反映はv2以降の課題です。
- **距離・交通費の計算**: 直線距離をもとにした簡易なロジックです。実際の経路・乗換、新幹線・特急、直行便の有無、時期による運賃の変動は反映していません。航空券は距離に比例する計算のため、短い路線は実際より安く出やすいです。経路探索APIとの連携は、APIキー管理・利用料が別途発生します。
- **ガソリン価格**: `docs/app.js` の `GAS_PRICE` に固定値(170円/L)で入れています。大きく変わったときは更新してください。
- **食事の提供条件**: 189校中、公表資料から提供条件(何食・何曜日)を判定できたのは77校です。残りの学校は加算せず「学校への確認事項」に表示しています。学校から情報を集め、`scripts/meal_provision.py` に追記すれば反映できます。
- **受検料**: 公立高校の一般的な目安(2,200円)を一律で使用しています。学校・自治体により異なります。

## データの更新方法

1. `data/schools_master.tsv` を最新の学校一覧で更新(必要に応じてChromeブラウザ等で再取得)。
2. 各校ページから学費・生活費テキストを再取得し、`data/raw_dump_part*.txt` に保存。
3. `python3 scripts/parse_raw.py` を実行して `data/schools_cost_data.json` を再生成。
   続けて `python3 scripts/parse_fee_detail.py` を実行して、表示用の明細 `data/fee_details.json` を再生成。
   学校が増えたときは `scripts/school_kana.py` に読みがなを追加して実行(`data/school_kana.json` を再生成)。
4. `python3 scripts/enrich_prefecture.py` を実行して都道府県情報を付与。
5. 食事提供条件を見直す場合は `scripts/meal_provision.py` を編集して実行。
6. `python3 scripts/build_site_data.py` で `docs/data/schools.json` を再生成。
7. `docs/` の内容をGitHubにpushすれば、GitHub Pagesで自動的に反映されます。
