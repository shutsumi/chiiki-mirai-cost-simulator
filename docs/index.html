このシミュレーターでわかること

地域みらい留学では、住んでいる都道府県を離れて、別の地域の高校に進学します。「学校を見に行くには、いくらかかる？」「入学したら、毎月いくら必要？」といった、お金の疑問に答えるためのツールです。お住まいの都道府県と志望校を選ぶだけで、次の費用の目安がわかります。

  • 検討時の費用オープンスクールや受検で学校に行くときの交通費・宿泊費など
  • 留学後の費用入学後にかかる月々の生活費・お小遣いや、帰省にかかる費用など

ご家庭での話し合いや、お金の準備の参考にお使いください。

ご利用にあたって

  • 本シミュレーターで算出される金額は、公表資料をもとにした概算値です。実際の金額とは異なる場合がありますので、詳細は必ず各学校・自治体へご確認ください。
  • 交通費・帰省費は概算です。
  • 一部の費用については地方自治体から補助が出る場合もあります。詳細は各学校へご確認ください。

  • 交通費は1人分の往復、宿泊費は1人分で計算します。宿泊日数は、1回の訪問で泊まる日数を選んでください。
  • 現在の居住地と志望校の距離が離れている場合は、宿泊日数が増えることを想定してください。
  • 地域みらい留学校のある地域は公共交通機関の本数が少ない場合がありますので、想定より移動時間がかかることがあります。
