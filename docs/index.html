留学したら毎月いくら？シミュレーター

志望校を選ぶと、入学後に毎月かかる費用の目安がわかります

学校ページの公表額をもとにした目安です

このシミュレーターでわかること

  • 毎月かかる費用寮費などの生活費と、月割りにした学校の費用の合計
  • 入学のときにかかる費用入学金・制服・教科書など、最初にかかる費用の項目
  • 年に何回かかかる費用帰省の交通費など

ご利用にあたって

  • 金額は、地域みらい留学の各学校ページに載っている金額をもとにした目安です
    実際の金額は、学校・自治体にご確認ください
  • 住まいの種類(寮・シェアハウスなど)や年度によって金額が変わるため、「〜」をつけて表示しています
  • 自治体から補助が出る場合があります、くわしくは各学校へお問い合わせください
  • 選んだ学校は、個人が特定されない形で記録し、サービスの改善に利用します

学費・生活費のデータは「地域みらい留学」公式サイトの各校ページ(2026年9月29日時点)をもとにしています
